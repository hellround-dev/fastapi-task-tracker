# FastAPI Task Tracker 🚀

Асинхронный REST API сервис для управления задачами (упрощённый аналог Todoist/Trello), построенный по стандартам коммерческой разработки на Python.

## 🛠 Технологический стек

* **Язык:** Python 3.12+
* **Веб-фреймворк:** FastAPI (асинхронные эндпоинты, Pydantic-валидация)
* **Менеджер зависимостей:** Poetry
* **База данных и ORM:** PostgreSQL 16, SQLAlchemy 2.0 (`psycopg 3`)
* **Кэширование:** Redis (`redis.asyncio`) с автоматической инвалидацией
* **Очереди и фоновые задачи:** Celery + RabbitMQ
* **Контейнеризация:** Docker & Docker Compose (5 изолированных сервисов)
* **Тестирование:** Pytest & HTTPX (интеграционные тесты)
* **Качество кода:** Black & Flake8 (соблюдение стандартов PEP 8)

## ✨ Ключевые возможности

* **Полный CRUD-цикл** для управления задачами (`POST`, `GET`, `PATCH`, `DELETE`) со строгой валидацией схем через Pydantic.
* **Асинхронное кэширование** списка задач в оперативной памяти (Redis) со временем жизни ключа (TTL) и мгновенным сбросом кэша при изменении данных в базе.
* **Фоновая обработка задач:** при создании новой задачи отправка уведомления выносится в очередь RabbitMQ и выполняется воркером Celery в фоне без задержки ответа пользователю.
* **Полная контейнеризация:** вся инфраструктура (веб-сервер, БД, кэш, брокер сообщений и фоновый воркер) поднимается одной командой.

## 🚀 Как запустить проект

### 1. Клонировать репозиторий
```bash
git clone https://github.com
cd fastapi-task-tracker
```

### 2. Запустить всю инфраструктуру в Docker
Убедитесь, что у вас запущен Docker Desktop, и выполните:
```bash
docker compose up --build
```
Docker автоматически поднимет 5 контейнеров:
* `task_tracker_web` — сервер FastAPI (порт `8000`)
* `task_tracker_postgres` — база данных PostgreSQL (порт `5432`)
* `task_tracker_redis` — кэш Redis (порт `6379`)
* `task_tracker_rabbitmq` — брокер сообщений RabbitMQ (порт `5672`, веб-панель на `15672`)
* `task_tracker_worker` — фоновый обработчик задач Celery

### 3. Открыть документацию API
После запуска интерактивная документация (Swagger UI) доступна по адресу:
`http://127.0.0.1/docs`

## 🧪 Запуск автотестов и линтеров

Установите зависимости для разработки и запустите проверки:
```bash
poetry install
poetry run pytest
poetry run flake8 .
```
